# Nota News

Nota News é um projeto pessoal bem antigo e resolvir fazer uma refatoração no código. Mantendo as mesmas funcionalidades que tinha anteriormente.

## 🎯 Objetivo do Projeto
É um projeto de noticias curtas em formato de notas que tem titulo, descrição e fonte da noticia retirada. é como se fosse um resumo da noticia em que você ler no dia a dia. e isso facilita na hora de entender o que se tratar antes de ler a noticia inteira pela fonte fornecida.

---

### Inicial
![Print da Tela do Home](https://archive.org/download/home_20260817/home.PNG)

Logo no começo um banner sobre o site, e logo abaixo as postagens das notas e acima tem uma barra de pesquisa para pesquisar diferentes assuntos.

---

### Noticia
![Print da Tela Noticia](https://archive.org/download/home_20260817/noticia.PNG)

Aqui é uma das notas que foi publicado como demonstrativo de como seria exatamente, onde tem titulo, descriçao, horário da publicação, fonte e também um espaço de Denúncia, caso o usuário entenda que foi escrito de forma desatualizado, distorcido ou completamente falso, pode reportar para a analise.

### Login
![Print do login](https://archive.org/download/home_20260817/login.PNG)

A tela de login é um espaço que o Administrador vai ter acesso para controlar o sistema.

### Painel
![Print do painel](https://archive.org/download/home_20260817/painel.PNG)

O Painel é onde o Administrador vai ter acesso ao realizar o login. E tem várias abas de exploração como postagem, cadastro e denúncia. Essa tela que o ADM vai fazer as postagens.

### Aba de Postagens
![Print de postagens](https://archive.org/download/home_20260817/postagem.PNG)

Onde vai ter o controle das publicações feitas como editar ou Deletar a publicação.

### Aba de Cadastro
![Print de cadastro](https://archive.org/download/home_20260817/cadastro.PNG)

Um lugar onde o Administrador vai cadastrar outros usuários para ter acesso ao sistema. criando um usuário e senha.

### Aba de Denúncia
![Print de denuncia](https://archive.org/download/home_20260817/denuncia.PNG)

Denúncias feitas pelos leitores das notas, caso os usuários encontrem alguma divergência na nota em si. e o Administrador vai ter o papel de fazer essa analise e caso realmente tenha alguma coisa, ele pode excluir a publicação diretamente pelo ticket enviado pelo usuário.

## 🛠 Tecnologias Utilizadas

* **Frontend:** Tailwind CSS.
* **Backend:** PHP 8.5.
* **Banco de Dados:** MySQL 8
* **Desenvolvimento:** IDE: VSCODE, Local: XAMPP
